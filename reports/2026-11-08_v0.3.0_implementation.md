# ХРОНОС Ω v0.3.0 — отчёт реализации

Дата сборки: 2026-11-08. Статус: рабочий локальный прототип; научные эксперименты не проводились.

## Реализовано

1. `SourceIndex`: локальный SQLite-реестр содержимого, SHA-256, дедупликация обновлений по пути, полнотекстовый FTS5-поиск с fallback LIKE. Форматы TXT/MD/CSV/JSON/HTML; текстовые PDF через необязательный `pypdf`. Для сканированных PDF OCR не включён.
2. `AETERNA MEMORY`: демонстрационный JSON-граф и CLI-поиск по идентификаторам, меткам и свойствам. Библиотечный граф сохраняет проверки допустимых типов и классов доказательности; документированные рёбра требуют `source_ids`.
3. `RUSSIA HISTORIA`: импорт наблюдений в SQLite с валидацией дат ISO, числовых значений, географии, источника и класса доказательности; запрос упорядоченного ряда по индикатору/географии.
4. `KOZYREV LAB`: KZ-01 draft с условиями motor-off, spinning, motor-only locked и static mass; первичным исходом, рандомизацией, ослеплением аналитика, контролями, безопасностью и планом анализа.
5. CLI, пакетная структура, инструкции установки, шаблон CSV, тесты.

## Ограничения

- В комплект не внесены вымышленные исторические ряды: шаблон `observations_template.csv` содержит только заголовок. Данные должны импортироваться из проверенных источников с сохранением методологии и источника.
- Граф AETERNA — стартовый пример, а не полная онтология истории человечества.
- Индексирование не загружает автоматически интернет-источники; документы сначала должны быть получены законным способом и добавлены локально.
- PDF-поддержка извлекает текстовый слой. Для сканов потребуется OCR с последующей ручной проверкой.
- KZ-01 имеет статус `DRAFT_NOT_PREREGISTERED`. Значения размера выборки/блоков — предварительные проектные параметры, которые необходимо обосновать пилотной оценкой дисперсии, зафиксировать до основного опыта и зарегистрировать во внешнем репозитории протоколов. Никаких результатов опыта не заявляется.
- Экспериментальный план не является воспроизведением всех исторических установок Козырева; это узкий современный тест механического эффекта гироскопа с контролями.
